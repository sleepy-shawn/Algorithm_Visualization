# Hot 100 模块 M0 操作手册（建表 + 种子数据）

> 目标：启动一次后端，数据库自动出现 3 张表并灌入 9 个分类、20 道题目。
> 全程不需要手写 SQL，JPA 的 `ddl-auto=update` 会根据实体类自动建表。

## 本阶段新增的文件（已写好并编译通过）

```
backend/src/main/java/com/algorithmviz/
├── entity/
│   ├── ProblemCategory.java   # 分类表（表名 problem_category）
│   ├── Problem.java           # 题目表（表名 problem）
│   └── ProblemSolution.java   # 题解表（表名 problem_solution）
├── repository/
│   ├── ProblemCategoryRepository.java
│   ├── ProblemRepository.java
│   └── ProblemSolutionRepository.java
└── config/
    └── DataSeeder.java        # 启动时自动灌入种子数据（9 分类 + 20 题）
```

三张表的关系：`problem.category_id → problem_category.id`，`problem_solution.problem_id → problem.id`。

## 操作步骤

### 第 1 步：启动 MySQL 容器

1. 打开 Docker Desktop（开始菜单启动，等右下角鲸鱼图标变绿/稳定）
2. 然后在终端执行：

```bash
docker start algorithm-mysql
docker ps                          # 确认 STATUS 是 Up
```

### 第 2 步：启动后端（首次会自动建表 + 灌数据）

PowerShell：

```powershell
cd C:\Users\23145\WorkBuddy\2026-09-05-16-22-57\pr-test-clone\backend
$env:DB_PASSWORD='123456'
& "C:\tools\apache-maven-3.9.16\bin\mvn.cmd" -s maven-settings.xml spring-boot:run "-Dspring-boot.run.arguments=--server.port=8080"
```

> - `DB_PASSWORD=123456` 是容器 MySQL 的 root 密码（见 `docker inspect algorithm-mysql` 的 `MYSQL_ROOT_PASSWORD`），必须设置，否则连不上数据库。
> - 命令行参数 `--server.port=8080` 用于强制端口：某些环境注入的变量会把端口改成别的值（如 62712）导致启动失败，加上最稳妥。

启动成功的标志：日志最后出现 `Started AlgorithmVizApplication`，并且能看到
`[DataSeeder] Hot 100 种子数据灌入完成：9 个分类，20 道题目`。

### 第 3 步：验证数据库里的表和数据

新开一个终端：

```bash
docker exec -it algorithm-mysql mysql -uroot -p123456 algorithm_viz -e "SHOW TABLES;"
docker exec -it algorithm-mysql mysql -uroot -p123456 algorithm_viz \
  -e "SELECT p.id, p.title, p.difficulty, c.name AS 分类 FROM problem p JOIN problem_category c ON p.category_id=c.id ORDER BY p.order_index LIMIT 25;"
```

预期看到 `problem`、`problem_category`、`problem_solution` 三张表，以及 20 行题目数据。

### 第 4 步（可选）：停掉后端

终端里按 `Ctrl + C` 即可。再次启动时 DataSeeder 检测到 problem 表已有数据会自动跳过，**不会重复插入**。

## 常见问题排查

| 现象 | 原因 | 解决 |
|------|------|------|
| `Communications link failure` | MySQL 容器没启动 | 执行第 1 步 |
| `Access denied for user 'root'` | 密码不对 | 用 `-p123456`（容器真实密码），并确认 `$env:DB_PASSWORD='123456'` 已执行 |
| 想清空重来 | 种子数据只想灌一次 | `docker exec -it algorithm-mysql mysql -uroot -p123456 algorithm_viz -e "DROP DATABASE algorithm_viz; CREATE DATABASE algorithm_viz;"` 然后重启后端 |
| `Access denied for user 'root'` | 密码不对 | 用 `-p123456`（容器真实密码），并确认 `$env:DB_PASSWORD='123456'` 已执行 |
| `Port 62712 was already in use` 等端口报错 | 环境变量覆盖了 server.port | 启动命令末尾加 `"-Dspring-boot.run.arguments=--server.port=8080"` |
| 端口 8080 被占用 | 其他程序占了端口 | `netstat -ano | findstr :8080` 找到进程后关闭，或改 application.properties 的 server.port |
