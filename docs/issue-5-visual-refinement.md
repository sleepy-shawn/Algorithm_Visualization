# [前端 A] 精简界面，统一图标、配色与动效

## 主旨

以简洁为核心，让算法内容成为视觉重点。减少不必要的文字，统一精致的线条图标，用充足留白、低饱和配色和自然动效，建立清爽、有质感的学习界面。

## 改进范围

- **文案**：删除重复标题、功能介绍和显而易见的操作说明；保留必要的步骤解释、输入约束和错误提示。
- **图标**：统一线条、尺寸和视觉重量，替换混用的文字符号与装饰图标；仅图标按钮提供悬停提示和可访问名称。
- **布局**：统一间距、对齐、圆角和层级，减少重复边框与卡片嵌套，让主要操作和算法图形更突出。
- **配色**：以浅色中性底和克制的淡橙色为主，图表采用柔和状态色；文字清晰，状态含义一致。
- **动效**：页面切换、按钮反馈和面板展开轻柔流畅；常规反馈160–240ms，无持续装饰动画，支持系统“减少动态效果”。算法播放节奏另按教学需要处理。

## 验收标准

- [x] 首页、目录、学习页和登录页没有重复或无助于操作的说明。
- [x] 主要控件使用统一 SVG 图标，鼠标和键盘操作都能辨认用途。
- [x] 390、768、1440px 宽度下内容清楚、控件不遮挡，页面无横向溢出。
- [x] 配色、间距和动效集中定义；图表状态同时有文字、图例或形状辅助区分。
- [x] 导航、搜索、输入、播放和对比功能正常；附关键页面截图及验证结果。
