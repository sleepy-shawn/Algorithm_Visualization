# 当前版本与 base 的区别

> 本文保留 2026-09-05 的阶段记录。最新界面与验收见 [Issue #5 前端交付](issue-5-delivery.md)。
如需了解本项目与此前推荐的国外 **Algorithm Visualizer** 的区别，请看 [外部项目对比](algorithm-visualizer-comparison.md)。本文只比较本仓库原版与当前改版。

对比基准：个人仓库 `sleepy-shawn/Algorithm_Visualization` 的提交 `fea5eba`（`chore: stabilize local Docker deployment`）。日期：2026-09-05。本文比较该提交与当前工作区，包含第一周布局改版和本次精简修改；不是新增算法成果说明。

上游原版为 `wenuanhappy/algorithm-viz-platform` 的 `db418da`（本地 `upstream/main` 指向该提交）。`db418da` 到 `fea5eba` 仅修改前后端 Dockerfile、增加 Maven 镜像配置，前端产品代码相同。因此，下表中的功能和界面差异也适用于与该上游 base 的比较；部署修复单独归于 `fea5eba`。

## 逐项对比

| 项目 | base（fea5eba） | 当前版本 |
| --- | --- | --- |
| 学习入口 | 登录后直接进入可视化面板；顶部同时包含助手、竞赛、测试、历史 | 登录后进入首页；主导航仅保留首页、算法目录、可视化学习 |
| 首页与目录 | 没有独立首页、可搜索的目录页 | 新增常用算法、分类入口，以及搜索、分类筛选、数量和空结果提示；复用原有 16 个算法／数据结构入口 |
| AI 学习助手 | 代码复杂度分析、多轮对话弹窗及 API 调用 | 删除前端入口、弹窗组件、相关状态、分析 API 客户端方法及遗留的聊天会话服务 `chat.service.ts` |
| 1v1 竞赛 | 竞赛页面、房间状态、WebRTC 对战客户端 | 删除前端页面、竞赛 store、竞赛 API、WebRTC 服务及专用模型 |
| 评估测试 | 设置页、固定题库、AI 出题与答题评估 | 删除前端组件、题库、评估状态和 API 客户端方法 |
| 历史记录 | 历史列表、分类查询及删除操作 | 删除前端页面和查询／删除 API 客户端方法 |
| 播放速度 | 0.5×、1×、2×、4× 四档 | 删除速度选项、速度状态和调节方法；自动播放采用固定 500ms 间隔。保留运行、播放／暂停、前后单步、首尾步、进度和重置 |
| 输入与随机生成 | 彩色 emoji 作为标题和随机按钮图标 | 使用统一 18px 线条 SVG；数组括号、交叉箭头与播放控件统一线宽；各类别统一“随机生成”标签，输入框和按钮至少 36px 高；移动端播放与进度分行 |
| 首页与登录页文案 | base 无首页；原登录页介绍平台功能 | 直接说明“选个算法，看看它怎么运行”，介绍输入、执行步骤和算法对比；首页画出 28 和 20 交换前后的数据及下一次比较，常用算法说明具体观察内容。移除宣传式表达、英文口号和已删除的练习功能描述 |
| 页面视觉 | 深色页面、饱和蓝紫色操作和图表高亮 | 浅灰蓝页面、白色卡片、蓝色主操作；不延续上一轮陶土品牌色与仿品牌式标题。保留清楚的层级和间距 |
| 图表颜色 | 深色背景上的饱和状态色；上一轮曾使用深黄、深绿 | 以浅蓝、浅粉、浅绿、浅黄、浅橙区分状态；覆盖排序、查找、图节点／边、背包、皇后棋盘、递归树、阶段进度、指标条和 3D 模型。补充背包／棋盘／递归树图例；数字保留深色，修复 Karatsuba 伪代码深底深字的高亮 |
| 窄屏布局 | 桌面固定侧栏和并排区域为主 | 小于 1024px 使用算法抽屉；小于 768px 对比区域上下排列；图表区域内部滚动 |
| 账户显示 | 直接读取 displayName | 空显示名回退用户名；长名称截断并可查看完整 title |
| 页面切换 | 播放与请求容易跨页面继续 | 切换算法、离开学习面板时停止两个播放计时器；重置／切换后忽略旧请求返回 |
| 验证 | 原有基础单元测试 | 增加目录、账户、页面切换及真实后端浏览器流程验证，覆盖 390／768／1440px |

## 图表配色

图表填充独立使用 `--viz-*` 变量，与深色文字、按钮及焦点色分开。图例同步采用对应填充色。

| 颜色 | 色值 | 典型用途 |
| --- | --- | --- |
| 浅蓝 | `#CFE1F5` / `#B8D8FA` | 默认元素／当前访问 |
| 浅粉 | `#F7C8DC` | 交换、查找中点、冲突提示、背包回溯路径 |
| 浅绿 | `#C5E6CF` | 已完成、已访问、已找到 |
| 浅黄 | `#FAEAA6` | 比较、队列、边界 |
| 浅橙 | `#FAD4B4` | 排序基准值、当前递归节点、皇后回溯移除、部分 3D 状态 |

3D 场景继续使用深色背景，模型和动画状态改用浅色；模型材质不透明度提高到 0.92，避免浅色在深底上发灰，数字使用深色字和白色描边。状态仍通过图例、数字、文字说明及选中描边辅助识别。

## 变更范围

此次删除指前端产品功能和对应客户端代码。后端 AI／竞赛／测试／历史接口、数据库表和已有用户数据仍保留；算法运行接口仍可能按原后端行为写入历史。本次没有清空记录或改动数据库。

排序、查找、图算法、背包、N 皇后、Karatsuba 和 3D 数据结构的计算／执行逻辑沿用 base。首页、目录、文案、图标、响应式布局和配色属于体验改进，不应表述为新实现了这些算法。没有新增 Hot 100、通用逐行代码高亮或新的公平对比协议；Karatsuba 原有伪代码行高亮仅修复配色。

本地源码预览地址为 `http://127.0.0.1:4200`。已有 `8082` Docker 前端镜像需要重新构建才会包含改动。验证记录和截图见 [前端交付说明](frontend-week-one.md)。
